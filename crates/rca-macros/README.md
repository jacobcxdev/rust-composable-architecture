# rca-macros

Enable `macros` on [`rca`](../rca/README.md) to generate dependency keys,
client endpoints, typed paths, and snapshots. A simple reducer needs no macro.

See [when to use a macro](../../docs/guides/authoring.md#macros-are-optional).
For a published version, select it in the [API reference](https://docs.rs/rca-macros).
