# rca-core

This crate defines RCA's Store, reducers, effects, and runtime interfaces.
Runtime adapters and libraries that need only the core can depend on it directly.
For application code, start with [`rca`](../rca/README.md).

Read the [host integration guide](../../docs/usage/integration-boundaries.md).
For a published version, select it in the [API reference](https://docs.rs/rca-core).
