# Rust Composable Architecture

This package re-exports [`rca`](../rca/README.md). Both package names
give you the same API, features and Rust types when used at the same version.

For a published release, choose one command:

- `cargo add rca` uses the canonical package.
- `cargo add rust-composable-architecture --rename rca` uses the long package name and keeps the `rca` import.

Run the [counter from a checkout](../README.md#quick-start). For a published version,
select it in the [API reference](https://docs.rs/rust-composable-architecture).
