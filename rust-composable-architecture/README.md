# Rust Composable Architecture

This package re-exports [`rca`](https://crates.io/crates/rca). Both package names
give you the same API, features and Rust types when used at the same version.

Use `cargo add rca` for the canonical package. To use the long package name and
keep the `rca` import in your code, run `cargo add rust-composable-architecture --rename rca`.

Read the [RCA guides and examples](https://github.com/jacobcxdev/rust-composable-architecture#quick-start)
to get started.
